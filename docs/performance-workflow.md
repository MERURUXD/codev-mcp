# 对比流程的有界会话复用

单镜头评价和双镜头对比默认每项分析独立会话。显式传 `--max-analyses-per-session 2..8` 后，同一镜头的每个会话最多执行指定数量的连续分析；预检仍单独会话，不跨镜头复用。单变焦的一阶、点列、数值 MTF、WAV 与五类原生图均可复用，也支持完整规格评价；多变焦拒绝复用。全部 COM 调用仍在所属工作进程的单线程上串行执行。

```powershell
python -m codev_mcp.compare --lens D:\lenses\design.len --spec docs/design/design-spec-dbgauss.json --max-analyses-per-session 8
```

## 状态与失败处理

每项分析核对前后公共镜头状态、任务来源与设置。WAV 保留完整快照核对；原生图成功、失败或取消时执行 `GRA T` 收尾。单项计算失败或截断时关闭当前复用组，只有清理确认后才从输入快照开新会话继续其余项，总体仍为失败。会话失效、状态漂移、超时、协议故障或清理未确认时停止。

该参数是有界编排选项，不是 CODE V 的固定安全调用阈值。是否减少耗时取决于镜头、分析种类、采样和许可证环境。

## 查看耗时

每个对比包的 `manifest.json` 中，`performance.sessions` 记录客户端初始化、CODE V 启动、镜头打开、释放、实际 COM 调用量和清理确认；分析条目记录计算、导出与回读耗时。

这些是墙钟时间，不是纯 CODE V CPU 时间。计算耗时包括 MCP 提交及轮询，导出耗时包括本地产物与图像核对。CODE V 启动时间包含在镜头打开时间内，两者不能相加。复用模式的启动和释放只计入所属会话，不应为每项分析重复相加。模拟后端不提供 CODE V 启动时长或 COM 调用数。
